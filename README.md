# Krypta
Developed by DaKaR.

**Krypta** is a professional-grade cryptographic suite designed for secure file encryption and decryption. Built on the robust Fernet (AES-128) implementation from the Python cryptography library, it provides a reliable and easy-to-use solution for protecting sensitive data.

## Features
- **Strong Encryption**: Utilizes symmetric encryption via the Fernet standard.
- **Standalone Executables**: Pre-compiled .exe versions for Windows environments.
- **Python Powered**: Clean and efficient codebase for developers and security enthusiasts.
- **Minimalist Design**: Focused on core security functionality.

## Usage
Users can utilize the pre-compiled binaries in the dist/ directory or run the source scripts using Python 3.14.

### Requirements
- Python 3.14+
- cryptography library
