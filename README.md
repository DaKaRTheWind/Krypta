<a name="english"></a>
## English

Developed by **DaKaR**.

**Krypta** is a professional-grade cryptographic suite designed for secure file encryption and decryption. Built on the robust Fernet (AES-128) implementation from the Python cryptography library, it provides a reliable and easy-to-use solution for protecting sensitive data.

### Features
- **Strong Encryption**: Utilizes symmetric encryption via the Fernet standard.
- **Standalone Executables**: Pre-compiled .exe versions for Windows environments.
- **Python Powered**: Clean and efficient codebase for developers and security enthusiasts.
- **Minimalist Design**: Focused on core security functionality.

### Usage
Users can utilize the pre-compiled binaries in the dist/ directory or run the source scripts using Python 3.14.

### Requirements
- Python 3.14+
- cryptography library

## Español

Desarrollado por **DaKaR**.

**Krypta** es una suite criptográfica de nivel profesional diseñada para el cifrado y descifrado seguro de archivos. Basada en la robusta implementación Fernet (AES-128) de la librería cryptography de Python, ofrece una solución confiable y fácil de usar para proteger datos sensibles.

### Características
- **Cifrado Fuerte**: Utiliza cifrado simétrico mediante el estándar Fernet.
- **Ejecutables Independientes**: Versiones .exe pre-compiladas para entornos Windows.
- **Potenciado por Python**: Código limpio y eficiente para desarrolladores y entusiastas de la seguridad.
- **Diseño Minimalista**: Enfocado en la funcionalidad central de seguridad.

### Uso
Los usuarios pueden utilizar los binarios pre-compilados en el directorio dist/ o ejecutar los scripts fuentes usando Python 3.14.

### Requisitos
- Python 3.14+
- Librería cryptography
